# Phishing Awareness Website

A cybersecurity awareness website created to help users understand phishing attacks, recognize common warning signs, and learn how to protect their personal information.

## About the Project

This website explains how phishing attacks work and how attackers use fake emails, messages, websites, and social engineering techniques to trick users into revealing sensitive information.

## Features

- **What is Phishing?**  
  An introduction to phishing attacks and how they can be used to steal sensitive information.

- **How to Recognize Phishing**  
  Common warning signs such as suspicious sender addresses, urgent messages, fake links, spelling mistakes, and unexpected attachments.

- **Real-World Examples**  
  Simulated phishing email examples demonstrating common red flags, including fake domains, urgency, and unexpected payment requests.

- **Social Engineering Tactics**  
  Information about psychological manipulation techniques such as urgency, authority, fear, curiosity, and trust.

- **How to Protect Yourself**  
  Practical security tips including checking URLs, using two-factor authentication, keeping software updated, and verifying suspicious messages through trusted channels.

- **Knowledge Quiz**  
  An interactive quiz designed to test the user's understanding of phishing awareness.
